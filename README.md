# Yusuph Aisha Said — CV Website

## Files
- `index.html` — CV content and page structure
- `css/styles.css` — responsive design and print styling
- `js/script.js` — Save/Print CV button
- `assets/aisha-passport.jpg` — supplied portrait photograph

## Preview locally
Open `index.html` in a browser. Internet is only needed for the optional Google Fonts; the CV itself works without them.

## Deploy with GitHub Pages
1. Extract this ZIP on your phone or computer.
2. Open your GitHub repository (`Killer-tz`).
3. Upload the **contents** of the extracted folder, keeping the `css`, `js`, and `assets` folders. Put `index.html` in the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then press **Save**.
7. Wait for GitHub Pages to publish. The website link will appear in the Pages section.

If GitHub asks whether to replace an existing file, only replace it if you intend this CV website to become the repository's main page.

## Save as PDF
Open the published page and press **Save / Print CV**, then choose **Save as PDF** in the browser print options.
